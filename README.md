# Портфолио Арама

Простой персональный сайт-портфолио с примерами учебных проектов: сайт-визитка, лендинг «Услуги» и страница с общим описанием.

## О проекте

Этот репозиторий содержит мои учебные и практические работы по HTML и CSS.  
Цель проекта — собрать аккуратное портфолио, показать навыки верстки и создать основу для первых коммерческих заказов.

## Страницы

- `index.html` — главная страница портфолио.
- `visiting-card/index.html` — сайт-визитка.
- `services/index.html` — лендинг «Услуги».

## Что умеет проект

- Адаптивная верстка.
- Аккуратные hero-блоки.
- Блоки с проектами, контактами и преимуществами.
- Единый визуальный стиль для нескольких страниц.

## Технологии

- HTML5
- CSS3
- Font Awesome
- Адаптивная верстка

## Как открыть

1. Склонируйте репозиторий.
2. Откройте `index.html` в браузере.
3. Перейдите в раздел с проектами и откройте нужную страницу.
